# 主题与 AI 自制主题

悬浮窗右键菜单、任务栏通知区域菜单均有独立的「主题」入口。内置四个主题，首次运行或旧版升级默认使用「经典（当前默认）」，选择其他主题后会自动记住。

| 主题 | 外观 | 余量指示 |
|---|---|---|
| 经典（当前默认） | 当前正在使用的浅色外观 | 原横条与原连续色阶 |
| 浅色原生 | 冷白、蓝色、清晰工具栏 | 横向进度条 |
| 深色仪表 | 石墨灰、薄荷绿 | 环形进度 |
| 柔和纸感 | 暖白、鼠尾草绿 | 竖向刻度 |

三个新主题的余量颜色随百分比连续过渡至暖红色。主额度与每周额度独立着色；数据缺失使用中性灰，DeepSeek 未设置预算时保留余额显示。主题选择不改变数据源、账户、历史记录、提醒或贴边交互。Windows 高对比度开启时以系统颜色为准。

## 用 AI 制作并导入

1. 打开「主题 → 导出 AI 主题制作套件…」，选择保存目录。
2. 将套件中的 `README.md`、`theme.schema.json`、`my-theme.json`、`display-contract.json` 提供给 AI，再描述希望的外观。`builtins/` 中有四套完整参考定义。
3. 请 AI 返回完整的 UTF-8 JSON，使用新的 `id` 和名称。不要把实际密钥或账户接口响应交给 AI，套件已包含演示值。
4. 打开「主题 → 导入主题…」，选择生成的 JSON。通过校验后会出现在主题列表并立即应用，重启后仍可使用。

可直接使用的提示词：

> 请依据附带的主题接口与 JSON Schema 修改 my-theme.json。只返回完整 JSON，保留 schemaVersion=1，使用新的小写英文 id 和中文名称。设计紧凑的 80×80 桌面余量窗与 400 宽的详情布局，保证长标签、未知状态、金额、低余量和深浅背景均清楚可读。利用 layout、colors、typography、shape 与 quotaColors 自制主题，高到低余量采用连续配色。不要增加未定义字段，不输出脚本、XAML 或网络资源。

## v1 接口范围

主题文件是独立的声明式 JSON。`layout.base` 选择布局骨架，`quotaStyle` 选择横条、圆环或竖条，`heroAlignment` 控制展开态数字对齐；圆环数字始终居中。经典骨架保留原布局，仅支持横条和左对齐。配色、字体、圆角、字号、进度条粗细和余量色阶均可定制。v1 支持这些布局组合，不支持通过主题导入任意界面代码。

| 字段 | 含义 |
|---|---|
| `schemaVersion` | 当前为整数 `1` |
| `id` / `name` / `description` | 唯一标识、菜单名称、说明 |
| `layout` | `base`、`quotaStyle`、`heroAlignment` |
| `colors` | 文字、背景、边框、统计区、按钮、标签和未知状态颜色 |
| `typography` | 本机文字字体、数字字体、紧凑和详情数字字号 |
| `shape` | 窗口圆角、卡片圆角、进度粗细 |
| `quotaColors` | 按 `percent` 递增的 `{percent,color}` 数组，覆盖 0–100，分段连续插值 |

显示数据契约由 `Get-RmfThemeViewModel` 提供，制作套件的 `display-contract.json` 包含同形状演示数据。`main` 是当前实际展示的额度窗口或余额，`weekly` 是补充窗口；`metrics` 是四组数据源统计及摘要；`trends` 是趋势、预测和监控摘要；`source`、`sampleTime`、`version` 分别对应底部信息。宿主负责窗口切换、账户读取、额度规则、图表、刷新与交互，主题无需重复实现。

## 存储与失败处理

内置定义位于 `src/Themes/Builtin/`，加载校验、渲染适配与制作套件分别位于同目录下的 `ThemeCatalog.ps1`、`ThemeHost.ps1`、`ThemeAuthoring.ps1`。打包程序会嵌入四套内置定义和制作接口，安装后无需源码目录。

自制主题存放在 `%LOCALAPPDATA%\RemainingMarginFloat\themes\`，可通过「打开自制主题目录」访问。每个文件最大 128 KB，最多载入 100 个。内置标识不能被覆盖，重复 id 会拒绝导入；格式、字段、色阶、尺寸与字体名称都会校验。损坏或缺失的已选主题会回退到经典并记录日志。导入不会执行主题中的脚本、XAML 或网络请求。

开发验证：`powershell.exe -NoProfile -File .\Test-Themes.ps1`。加 `-CaptureDirectory <目录>` 可生成四主题、三数据源、高低余量、紧凑及详情的真实 WPF 截图；诊断使用隔离的本机数据目录。
